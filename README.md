## About

The **T.M.M.V (N.S) Boy Scouts Website** is a dedicated online space for presenting troop information and useful interactive features. It brings together the troop's web content in a simple, accessible website.

## Website features

- Troop information and page content
- Interactive forms and enquiry facility
- Language and display features
- Countdown and roster-related functionality
- Responsive static website design

## Deployment

The repository includes `.github/workflows/deploy.yml` to publish the website from the root of the `main` branch using GitHub Pages.

1. Open repository **Settings → Pages**.
2. Select **GitHub Actions** as the deployment source.
3. Check the **Actions** tab for the deployment workflow.
4. After a successful deployment, visit the live website.

## Enquiries & privacy

The enquiry form is configured to use FormSubmit. The recipient may need to complete a one-time email activation before submissions are delivered. The form uses a third-party service; avoid submitting sensitive personal information.

## Launch information

The homepage countdown is configured for the planned launch date of **1 January 2027**.
